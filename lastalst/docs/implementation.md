## 구현
순수 WebGL color shader와 UI texture shader를 직접 작성했다. 3D 좌표를 CPU에서 사선 직교 투영하고 상자 면을 삼각형으로 그린다. 깊이 버퍼 대신 z 기준 물체 정렬을 쓰는 단순 공방 렌더러라 복잡한 3D 메시 교차를 처리하지 않는다. 화면에 붙는 canvas는 하나이며 텍스트/버튼은 메모리의 2D canvas를 WebGL 텍스처로 업로드한다. 외부 모듈/자산/네트워크 요청은 없다.

모델은 두 플레이어, 협동 작업 인계, 5/6/4초 자동 처리, 공동 주문, 제한 시간, 바닥 물건, 충돌 및 보호 시간을 포함한다. 충돌은 초당 120회 이하 간격으로 나눠 계산한다. 입력은 포인터별 소유권을 가지며 blur/visibility/cancel/lostcapture/resize에서 정리한다. 오디오와 진동은 포함하지 않았다.

## 수행한 검증
번들 개발용 Node로 tests/logic.cjs 실행: 9개 통과. 제작 4.99/5, 5.99/6, 3.99/4초 경계, 다른 플레이어의 회수/후속 투입/납품, 잘못된 재료/점유 거부, 바닥 인계, 빠른 충돌의 두 낙하/0.7초/기상 후 1초 보호, 느린 접촉/정확한 겹침 분리, 대각선 속도/장애물, 주문 만료/마지막 20초/180초 종료/재시작, 실제 근접 선택을 검사했다.

## 미검증과 제한
입력 모의 검사는 두 조이스틱 동시 이동, 세 번째 손가락 행동, pointercancel/lostpointercapture, 정확한 PC 키 매핑, blur 일시 정지/재개를 통과했다. 실행 JavaScript 4개 구문 검사도 통과했고 실행 HTML/소스에서 외부 URL·fetch·XHR·엔진 import가 없음을 확인했다. 이는 실제 브라우저 또는 터치 장치를 구동한 검사가 아니다.

실제 브라우저 file:// 열기를 시도했으나 브라우저 보안 정책이 해당 프로토콜을 차단했다. 차단을 우회하지 않았다. 따라서 새 구현의 GPU 셰이더 컴파일·화면 배치·콘솔 오류 없음·직접 파일 오프라인 실행·수동 전체 납품을 확인했다고 주장하지 않는다. 예전 구현 문서의 브라우저 통과 기록은 이 버전에 적용되지 않는다.

실물 태블릿의 동시 다중 터치/세로 가독성/키보드 고스팅/장치 성능/어린이 사용성도 미검증이다. 텍스트 텍스처를 프레임마다 업로드하므로 저사양 태블릿은 성능 측정 후 UI 갱신 빈도 최적화가 필요할 수 있다. WebGL 미지원이면 콘솔에 오류를 남기며 DOM 대체 화면은 만들지 않는다. WebGL context 복구 때 페이지를 다시 로드하므로 진행 중 판은 초기화된다.
