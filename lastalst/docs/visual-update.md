# 작업대와 물건 식별 개선

- PC/태블릿 모두 조이스틱 기본 표시. 화면 오른쪽 위 조이스틱 숨기기/보기 버튼으로 전환. 전환 및 화면 크기 변경 시 포인터/키 입력 정리.
- 작업대 아래 재료 요청/초 단위 남은 시간/완료 안내 텍스트 패널 제거. 작업대 위 진행 막대와 완료 체크만 표시. 작업대 이름은 유지.
- 창고는 열린 나무 상자와 실제 재료 도형, 가공대는 바이스/망치, 결합대는 고정구/접착 용기, 마감대는 천/붓/칠통, 출고대는 포장 상자와 화살표로 표현.
- 뿔은 끝이 가늘어지는 곡선, 활 몸체는 단일 곡선, 결합 몸체는 어두운 이중층/밝은 감은 띠, 완성 활은 활시위/파란 손잡이/붉은 끝장식으로 구별. 손에 든 상태·작업대 결과물·바닥 물건 모두 같은 형태 사용.
- 자산/엔진/네트워크 의존성 추가 없음. 게임용 형태이며 실제 공예 공법을 재현하지 않음.

검증: 실제 렌더러 메서드로 5종 물건의 서로 다른 도형 데이터/유한 좌표와 6종 작업대 경로 확인. 모의 환경에서 PC 기본 조이스틱 표시/클릭으로 숨김·다시 표시/작업대 아래 문구 부재 확인. 같은 도형 데이터로 소프트웨어 미리보기를 만들어 형태 확인. 구문 및 기존 게임·입력 검사를 재실행했다. 실제 브라우저 GPU/실물 태블릿 검증은 수행하지 않았음.
