# 화면 정리

실제 로컬 Arrow_Prototype/asfd의 파일을 확인하고 이를 복사한 수정본에서 변경했다. 이 원본 폴더는 쓰기 허용 범위 밖이므로 직접 변경하지 않았다. 변경 전 파일은 archive/before-ui-cleanup에 보존했다.

## 변경
- 소리 토글 버튼과 해당 명령을 제거했다. 납품 합성 효과음은 유지한다.
- 바닥의 지름길/넓은 통로 글자를 제거했다. 물리적인 길 구조는 유지한다.
- 계절 글자, 바닥 색 변화, 계절 음, 모델의 계절 계산을 제거했다. 주문의 45초/가상 1년 날짜는 유지한다.
- 작업대·건조대·전달 선반 이름표를 실제 표시 폰트로 measureText한 너비에 좌우 8씩 여백을 더하는 방식으로 변경했다. 높이도 글자 크기에 상하 여백만 더한다. 이름이나 선반 물건이 바뀌면 다시 측정한다.
- 게임 방법을 세 페이지로 나눴다. 만드는 순서 6개 카드, 협동 방법/조작법, 선택적 보너스 두 개를 따로 읽는다. 현재 페이지·이전/다음 버튼·마지막 시작 버튼을 제공한다. Enter도 설명을 순서대로 넘긴다.

## 검증
실행 소스 구문 및 기존 모델/동선/입력 검사, 수정한 UI 모의 검사를 실행했다. 게임 안내 세 페이지, 시작과 조이스틱 토글, 제거한 화면 요소의 부재를 확인했다. 실제 렌더러/UI 그리기 명령을 소프트웨어로 재생한 미리보기에서 제작 순서와 이름표 배치를 확인했다.

이는 실제 GPU·브라우저 화면 캡처가 아니다. 이번 UI의 실제 브라우저/태블릿 실행과 효과음 재생은 미검증이다. 기존 검사 기록을 이번 버전의 실제 실행 통과로 해석하지 않는다.
