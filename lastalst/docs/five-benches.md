# 해궁대 분리와 지도 조정

## 변경 내용
- 기존 4개 공정 작업대에서 5개로 확장했다. 몸체 3초 → 접합 4초 → 중앙 건조 3초 → 새 해궁 2초 → 화피단장 2초. 자동 처리 합계는 14초다.
- 해궁대는 오른쪽 아래 x=5.3/z=1.0에 있다. 기존 오른쪽 위 작업대를 화피단장 전용으로 바꿨다. 해궁 완료품은 ‘균형 잡은 활’로 표시하며 별도 형태·중앙 띠를 사용한다. 이를 꺼내 화피단장대까지 실제로 옮겨야 한다. 건조 몸체를 화피단장대에 바로 넣거나 균형 잡은 활을 출고하는 것은 거부한다.
- 해궁 균형 보너스는 해궁대의 2초 처리 중에만 받는다. 추가 화피단장 보너스는 완성 활을 들고 화피단장대에서 진행한다. 기본 100/보너스 하나 125/둘 다 150점을 유지한다.
- 전달 선반의 지도 위 이름표를 제거했다. 선반의 위치·보관·파트너 인계는 유지한다. 근접 시 하단 안내는 ‘맡기기 / 꺼내기’다.
- 중앙 지름길 옆 도구 보관대 길이를 3.4→4.2로 늘렸다. 크기 데이터와 실제 그리기를 통일하여 보이는 장애물과 충돌 범위가 달라지지 않게 했다. 폭과 중앙 건조대 크기는 유지했다.
- P2 시작 위치를 새 설비와 겹치지 않는 곳으로 옮겼다. 게임 설명은 제작 5단계+완성 카드로 바꿨다. 작은 이름표·세 페이지 안내·소리 버튼/계절/통로 글자 제거 상태를 유지한다.

## 검증 결과
- 모델 13개 검사 통과. 5개 공정 작업대와 14초 예산, 3/4/3/2/2초 경계, 해궁 중간 결과물/품질 인계/잘못된 입력과 출고 거부, 해궁대에서만 균형 보너스, 기본/125/150점, 선반·건네기·낙하·충돌·주문·초기화.
- 확장된 장애물의 유효 바닥을 따라 실제 이동/근접 행동을 사용하는 최적 경로 검사에서 **21.40초에 150점 활 납품**, 만료 0건. 실제 사용자의 플레이 기록은 아니다.
- 30초 만료/한 주문/다음 주문, 8방향 운반 위치·회전, 독립 포인터/키 입력 검사 유지.
- 렌더러 경로에서 7종 물건의 구별 도형과 유한 좌표, 새 해궁대 도형, 두 작업대의 별도 이름표, 선반 이름표 부재, 조이스틱과 안내 페이지를 모의 검사했다.
- 실행 JavaScript 구문 검사. 실제 게임의 도형·텍스트 그리기 명령을 소프트웨어로 재생해 지도 배치를 확인했다.
