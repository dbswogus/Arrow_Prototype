# 1년 주문과 방향 운반 개정

## 게임의 시간
각궁 제작에 약 1년이 걸리는 사례를 소재로 주문의 납기 1년을 45초로 압축했다. 기존 시작 65/90초 및 보충 80초에서 모든 주문의 납기를 45초로 통일하고 동시 주문을 한 건으로 줄였다. 화면에는 한 개의 의뢰 카드만 표시하며 남은 가상 날짜는 ceil(남은 초 / 45 × 365)다. 주문 완료/만료 시 새 주문의 달력은 다시 365일부터 시작한다.

한 판 180초, 공정 5/6/4초, 납품당 100점, 마지막 20초 주문 보충 중단은 유지한다. 실제 공정별 시간이나 모든 각궁의 정확한 소요일을 재현하는 시스템은 아니다. 납기 이전 조기 완료도 허용하는 캐주얼 제작 게임이다. 난이도가 달라져 최고 점수 저장 키를 분리했다.

기간 참고: [연합뉴스, 각궁 제작에 평생 바친 주장응 씨 인터뷰](https://www.yna.co.kr/view/AKR20100312160400063). 기사에서는 재료 준비와 계절에 따른 접착 작업을 포함해 대략 1년에 걸쳐 제작하는 사례를 소개한다. 특정 제작자의 사례이며 보편적인 정확한 소요 시간이라고 단정하지 않는다. 45초라는 값은 사용자 요청을 반영한 게임 설계 선택이다.

## 배치와 운반
공방 크기와 카메라 범위는 유지하고 작업대를 x=-7.2/0/7.2, z=-3.7/3.7에 배치했다. 위쪽은 몸체 창고/몸체 가공/마감, 아래쪽은 뿔 창고/뿔 결합/출고다. 충돌·근접 판정은 같은 배치 데이터를 사용한다.

운반 물건은 캐릭터의 로컬 전방 0.62에 두고 atan2(face.x,face.z)로 메시까지 회전한다. 정지해도 마지막 바라본 방향을 유지한다. 물건을 그리는 동안만 좌표 변환을 적용하고 finally에서 해제해 공방과 바닥 물건에 회전이 전파되지 않게 한다. 뒤를 향할 때는 물건→캐릭터, 앞을 향할 때는 캐릭터→물건 순으로 렌더링한다. 바닥 드롭은 기존의 전방 드롭/장애물 시 발밑 드롭 규칙을 유지한다.

## 검증과 한계
수정된 게임 모델의 기존 9개 검사와 입력 검사를 실행한다. 추가 검사는 45초 만료/한 주문 제한/달력 대응, 8방향 운반 좌표와 회전 정리, 넓어진 작업대 간격과 접근 가능성, 실제 이동과 행동을 거치는 납품 동선을 대상으로 한다. 실제 GPU·브라우저·태블릿에서 이번 변경 화면을 확인하지 않았으며 자동/모의 검사를 실제 플레이 검증으로 주장하지 않는다.

원본 ffff 폴더는 쓰기 허용 범위 밖이라 직접 반영하지 않았다. 별도 수정본을 제공한다.

## 실행 결과
게임 모델 9개 검사 통과. 입력 모의 검사 통과. 추가 4그룹(45초 만료/한 주문, 8방향 운반/변환 해제, 배치/접근, 실제 이동 납품) 통과. 단독 운반자의 자동 경로로 24.46초에 첫 납품, 만료 0건을 확인했다. UI 모의 검사에서 의뢰 카드 한 개/남은 날짜/두 번째 주문 부재/조이스틱 토글/작업대 아래 글씨 제거를 확인했다. 모든 실행 JavaScript의 구문 검사 통과. 자동 이동 시간은 최적 경로를 사용하는 개발 검사 결과이며 실제 사용자 플레이 기록이 아니다.
