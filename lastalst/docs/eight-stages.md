# 전시 사진의 8단계 반영 및 제작 시간 단축

## 기준 자료
사용자가 이 대화에 제공한 ‘각궁 제작과정’ 전시 사진을 기준으로 다음 순서를 반영했다.

1. 재료 손질
2. 활 몸체 만들기
3. 물소뿔 붙이기
4. 쇠심줄 올리기
5. 건조하기
6. 해궁하기
7. 화피단장
8. 각궁 완성

이는 사진의 단계 이름과 순서를 게임에 대응한 것이다. 전시 사진을 새 이미지 자산으로 배포하거나 세부 공법을 검증했다고 주장하지 않는다.

## 구현
기존 게임의 자동 처리 5/6/6/4초(21초)를 3/4/3/3초(13초)로 줄였다. 몸체 단계는 재료 손질/몸체 만들기 각 1.5초, 접합 단계는 뿔 붙이기/심줄 올리기 각 2초, 마무리 단계는 해궁/화피단장 각 1.5초로 화면의 공정 이름을 전환한다. 실제 소요 비율을 나타내는 수치는 아니다.

접합 재료는 뿔·심줄 묶음 하나로 운반한다. 묶음을 접합대에 넣으면 두 공정이 자동으로 순서대로 진행한다. 기존 horn 내부 타입을 유지해 입력/도형/보관 호환성을 지켰으며 플레이어에게 표시하는 이름과 형태를 수정했다.

건조는 3초 동안 자동 진행하며 뒤집기와 보너스를 제거했다. 대신 마무리 작업의 첫 1.5초 해궁 구간에서 빈손으로 균형 게이지를 맞추면 품질 +25. 실패·미시도에도 전체 마무리 작업은 3초에 끝나며 기본 해궁과 화피단장을 진행한 완성 활을 생성한다. 이미 완성된 활로 선택적인 추가 화피단장을 하면 +25. 기본 100점, 한 보너스 125점, 두 보너스 150점이다. 두 정밀 작업은 게임용 미니게임이다.

주문은 한 건씩 30초. 180초 판과 마지막 20초 새 주문 보충 중단은 유지했다. 플레이 HUD에서 가상 날짜와 ‘1년=몇 초’ 환산을 제거했다. 실제 약 1년에 걸리는 제작 사례와 게임용 축약은 안내와 문서에서 구분한다. 최고 기록 저장 키는 변경된 난이도에 맞춰 분리했다.

## 검증 결과
- 모델 13개 검사: 3/4/3/3초 경계, 13초 예산, 150점 완성, 자동 건조/뒤집기 부재, 균형 보너스 1회/해궁 구간 제한/실패 보호, 사진 단계 매핑, 화피단장 단독 125점, 기존 건네기/선반/낙하/충돌/주문/재시작 유지.
- 30초 만료 경계와 다음 주문 생성, 한 주문 제한.
- 실제 이동과 근접 행동을 사용하는 최적 경로 검사에서 해궁과 추가 화피단장 모두 포함해 **20.23초에 150점 납품**, 만료 0건. 자동 개발 검사이며 실제 사용자의 플레이 기록이 아니다.
- 8방향 운반 위치/메시 회전 및 좌표 변환 정리 검사.
- 독립 포인터/키보드 입력, 세 페이지 안내, 이름표/도형, 한 개의 주문 카드와 마감 초, 제거된 소리 버튼/계절/통로 글자 부재의 모의 검사.
- 실행 JavaScript 전체 구문 검사와 실제 그리기 명령을 소프트웨어로 재생한 안내 미리보기 확인.
