# 순서·마감 개정 검증
전체 소스 구문 검사, 모델 14그룹, 입력·UI·공정 설명/도형 모의 검사 통과. 마감 실패/시간 초과/중도 내려놓기의 10점 감점과 1회 제한, 선반 인계·낙하 후 유지 및 납품 점수를 검사했다. 중앙 아래 시작 위치는 충돌 영역 밖이다.
실제 이동·작업 시간을 사용하는 자동 경로에서 3개 납품: 단독86.67초, 분업58.62초. 분업 첫 납품29.22초로 30초 기한에 근접한다. 이상적인 자동 이동 결과이며 실제 사용자의 조작 난이도·재미를 증명하지 않는다. 이전 docs/team-learning.md 수치는 이전 시작 위치의 기록이다.
브라우저 GPU·실제 화면·태블릿·소리는 이번 개정에서 검증하지 않았다. 이전 전달본을 수정한 완전한 프로젝트이며 GitHub 원본 폴더는 변경하지 않았다. 압축을 풀고 index.html을 열어 실행한다.
