## 중요한 규칙
기본 100점에 건조 뒤집기 +25, 선택적 추가 마감 +25로 최대 150점이다. 실패해도 기존 품질은 낮아지지 않는다. 품질과 추가 마감 시도 여부를 물건과 함께 보관하여 바닥 드롭·선반·파트너 전달로 추가 마감을 반복할 수 없게 했다. 추가 마감 중은 이동이 멈추고 충돌/내려놓기로 중단된다.

건조대는 장식이 아니라 이동 장애물과 처리 시설이다. 중앙 설비의 오른쪽은 도구 보관대와 사이가 좁아 한 사람씩 지나고, 왼쪽은 넓은 통로와 전달 선반이 있다. 입력 키를 추가하지 않고 기존 행동 버튼의 근접 대상을 사용한다. 직접 건네기는 물건을 든 사람이 서로 마주 보고 행동한다.

소리는 브라우저 Web Audio의 sine oscillator로 합성한다. 키 또는 포인터 입력 후 오디오 컨텍스트를 만들고, 지원하지 않거나 재생이 차단되면 소리 없이 플레이한다. 계절 음과 납품 음은 소리 버튼으로 끌 수 있다. 외부 오디오 자산/네트워크 요청은 없다.

## 미검증
이 대화에서 브라우저 도구의 file:// 접근이 차단된 이후 우회하지 않았다. 이번 버전의 실제 GPU 셰이더/브라우저 렌더링/효과음 청취/실물 태블릿 입력/수동 한 판 완주는 확인하지 못했다. 기존 버전의 과거 검증 문구가 이 버전의 실제 실행을 뜻하지 않는다.

화면에 긴 건조대와 캐릭터를 배치하는 방식은 기존의 물체별 z 정렬을 유지하므로 복잡한 메시 교차를 완전하게 처리하는 깊이 버퍼 방식은 아니다. 사용자 테스트에서 설비 뒤 캐릭터 가림이나 좁은 길의 답답함을 확인해야 한다. UI 텍스처는 프레임마다 업로드하므로 저사양 태블릿 성능도 후속 측정 대상이다.

어린이와 실제 두 사람이 느끼는 재미/타이밍 난이도/동선 협동은 아직 평가하지 않았다. 공예의 실제 건조·뒤집기·칠 공법 및 기간을 재현한 것으로 해석해서는 안 된다.
