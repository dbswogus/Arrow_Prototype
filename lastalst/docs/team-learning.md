## 실제 공정이 보이도록 한 표현
연속 리본 도형으로 재료를 그려 이전의 작은 상자 조각 느낌을 줄였다. 몸체 위에 어두운 뿔 층, 밝은 심줄 가닥이 겹친다. 접합이 진행되면 고리 형태가 되고, 건조 뒤 해궁에서 점차 펴진다. 화피단장에서는 겉면을 감싸는 부분이 점차 늘어나고 손잡이와 시위가 완성된다. 재료/몸체/접합/건조/해궁/완성은 손·바닥·선반·작업대에서 같은 도형을 사용한다.

이 표현은 게임에서 단계를 구별하기 위한 도식이다. 실제 활의 치수·단면·변형률·건조 색 변화·모든 장인의 공법을 과학적으로 재현한 모델은 아니다. 고정띠와 색 차이도 식별 표현이다.

## 첫 작업의 한 문장 설명
실제 유효 작업을 처음 시작할 때만 표시한다. 잘못된 재료 투입은 설명을 소비하지 않는다. 같은 판의 반복 작업에서는 다시 나오지 않는다. 한 번에 하나씩 4초 표시하며 여러 공정이 시작되면 큐에 넣고, 게임 시간/이동/행동은 멈추지 않는다. 재시작 시 초기화한다.

| 공정 | 설명 문구 | 근거 |
|---|---|---|
| 몸체 | 나무를 손질해 활의 기본 몸체를 만들어요. | 사용자 제공 전시 사진의 ①·② |
| 접합 시작 | 부레풀로 나무와 뿔을 단단히 붙여요. | 아래 자료 A의 재료·결합 설명 |
| 심줄 단계 | 뿔·대나무·심줄이 함께 활의 탄력을 만들어요. | 아래 자료 B의 복합 재료 설명 |
| 건조 | 재료가 붙도록 말릴 때 온도와 습도도 살펴요. | 자료 A의 온도·습도와 접착·건조 설명 |
| 해궁 | 해궁은 활의 모양과 균형을 잡는 과정이에요. | 사용자 전시 사진의 ⑥, 자료 A의 도지개·궁창 설명 |
| 화피단장 | 겉면을 나무껍질로 감싸 습기로부터 보호해요. | 자료 B의 외피 기능 설명 |

자료 A: [국가유산진흥원 — 궁장 김박영과 각궁 재료·제작과정](https://kh.or.kr/brd/board/696/L/menu/314?bbIdx=110578&brdType=R&searchField=&searchText=&thisPage=1). 민어부레풀의 결합 역할, 온도·습도에 따른 접착/건조 조건, 각궁 제작과 관련 도구를 확인했다.

자료 B: [산업통상자원부 《함께하는 FTA》 2014년 8월, 김윤경 궁장 인터뷰, 인쇄면 40~41쪽](https://fta.motir.go.kr/webmodule/board/uploads/135/201408FTA_spreads%20page_low.pdf#page=22). 다른 재료를 함께 써서 탄성을 얻는 설명과 외피가 습기·물을 막는 기능을 확인했다. 실제 인터뷰의 전체 진술을 일반적인 제작 표준으로 확대하지 않고 짧은 설명에 필요한 재료 역할만 재서술했다. 사진과 긴 본문은 게임에 포함하지 않았다.

게임의 처리 시간·접합 재료 묶음·게이지 보너스는 위 출처에서 가져온 실제 공예 규칙이 아니다. 사용자와 합의한 게임용 축약을 유지한다.

분업은 첫 활을 즉시 더 빨리 만드는 구조가 아니다. 다음 활 준비와 이전 활 마무리를 겹쳐 연속 제작에서 유리해지는 구조다. 두 자동 시나리오의 입력은 실수·지연이 없고 정해진 정책을 따르므로, 이 수치를 실제 어린이 플레이나 재미·교육 효과의 실증 결과로 해석하지 않는다. 최선의 모든 플레이 전략을 탐색한 것도 아니다.

소프트웨어로 실제 도형/UI 명령을 재생해 넓어진 지도와 단계별 물건 외형을 확인했다. 이는 GPU 캡처가 아니다. 실행 소스 구문 검사와 새 런타임 네트워크 요청/외부 엔진 미추가를 확인한다.
