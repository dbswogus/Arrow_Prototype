# 각궁 공방 대소동 — 협동과 동선

두 장인이 공방을 나누어 맡고, 재료를 건네고, 건조 타이밍과 품질을 선택하는 2인 로컬 협동 게임이다.

## 유지하는 기준
순수 WebGL + 일반 JavaScript, 화면에 표시되는 canvas 하나, 공유 직교 카메라 하나, 외부 엔진/CDN/API/네트워크 로더 없음. Node/npm/Vite는 플레이에 필요하지 않다. 글자·버튼·조이스틱·미니게임도 오프스크린 2D canvas를 텍스처로 만들어 같은 WebGL canvas에 표시한다.

P1 WASD/F/G, P2 방향키/Enter/오른쪽 Shift. 태블릿은 각자 조이스틱/행동/놓기. 한 사람이 동시에 들 수 있는 물건은 하나. 기본 조이스틱 표시와 캔버스 토글을 유지한다. 빠른 상대 접근 충돌은 둘 다 0.7초 넘어짐·낙하·기상 후 1초 보호, 느린 접촉은 위치 분리한다.

공동 주문 한 건씩, 납기 45초. 가상 365일을 45초로 압축하여 날짜와 초를 함께 표시한다. 한 판 180초, 마지막 20초 새 주문 보충 중단. 실제 각궁 공예와 제작 기간을 그대로 재현하는 시스템이 아니다. 건조·뒤집기·품질 보너스도 게임용 축약 규칙이다.

## 지도와 길 선택
몸체·뿔 창고와 가공·결합 작업은 왼쪽, 마감·출고는 오른쪽이다. 중앙에는 폭 2.2/깊이 4.2의 건조대가 있어 직진할 수 없다. 오른쪽 도구 보관대와 건조대 사이 1.7 너비 통로는 빠르지만 두 사람이 나란히 통과하기 어렵다. 왼쪽 넓은 통로는 양보와 우회가 쉬우며 중간 전달 선반을 경유할 수 있다. 바닥 문구는 표시하지 않으며 실제 설비 배치와 바닥 선으로 길을 구별한다. 모든 설비는 실제 이동 충돌을 가진다.

## 기본 제작
몸체 창고 → 몸체 가공 5초 → 활 몸체와 뿔 재료를 결합대에 순서대로 투입 → 결합 6초 → 중앙 건조대 6초 → 건조 몸체 → 마감 4초 → 완성 활 → 출고.

작업대 상태는 idle/processing/ready. 한 작업대는 한 물건만 처리하며 다른 사람이 회수·후속 작업할 수 있다. 잘못된 재료를 소모하지 않는다.

## 협동
물건을 들고 1.55 거리 이내에서 빈손인 파트너와 마주 보고 행동하면 건넨다. 받는 사람의 추가 버튼 입력은 필요 없다. 두 사람이 모두 서 있고 물건이 벽·설비를 통과하지 않아야 한다.

전달 선반에는 물건 하나를 보관한다. 양쪽에서 행동하여 넣거나 꺼낸다. 꽉 찬 선반에 새 물건을 넣어 덮어쓸 수 없다. 바닥에 놓은 물건도 두 사람이 공유한다.

## 품질 선택
기본 활은 100점이다.
- 건조 시작 2~4.5초 사이 노란 표시가 켜진다. 빈손으로 건조대에서 행동하면 한 번 뒤집는다. 품질 +25. 놓쳐도 건조가 완료되어 기본 활을 제작할 수 있다.
- 완성 활을 들고 마감대에서 행동하면 선택적인 추가 마감을 시작한다. 표시가 초록 구간에 들어올 때 다시 행동하면 품질 +25. 성공 범위는 게이지 0.37~0.63이다. 3초 안에 마치며 실패·시간 초과에도 기존 품질은 유지한다.
- 추가 마감은 물건당 한 번. 시작하면 시도 여부를 기록하고 움직임을 멈춘다. 내려놓거나 충돌하면 중단되며 재시도로 보너스를 무한 획득할 수 없다.
- 건조와 추가 마감을 모두 성공하면 150점. 건조 성공만 하거나 추가 마감만 성공하면 125점. 추가 마감을 생략하고 빨리 납품해도 된다.

## 보상과 분위기
납품 시 포장 표시·점수 팝업·색종이와 합성 효과음을 재생한다. 계절 표시와 바닥 색 변화 및 계절 음은 사용하지 않는다. 소리 토글 버튼도 표시하지 않으며 납품 효과음은 유지한다. 음원 다운로드는 없다.

RESULT에는 납품/점수 외에 최고 품질 활 점수, 정성 활 개수, 최대 연속 납품, 직접 건네기 횟수를 표시한다. 정성 활은 품질 보너스가 있는 활이다. 주문 만료가 연속 납품 기록을 끊고 충돌은 끊지 않는다.

## 화면 흐름과 검증
TITLE → TUTORIAL → PLAYING → RESULT, 다시 하기/처음으로. 화면 이탈 시 시간을 멈춘다. 재시작은 지도상의 모든 물건·작업·품질·통계·효과를 초기화한다. 검증 결과와 미검증 범위는 docs/coop-expansion.md를 따른다.

## 안내와 이름표
TUTORIAL 내부에 세 페이지를 둔다. 1쪽은 6개 제작 단계 카드, 2쪽은 직접 건네기/전달 선반 카드와 P1/P2 조작법, 3쪽은 건조 뒤집기/추가 마감 선택을 설명한다. 이전/다음 버튼, 페이지 번호, 마지막 공방 시작 버튼을 제공한다. Enter도 페이지 순서대로 진행한다. 작업대·건조대·선반 이름표 배경은 해당 폰트로 측정한 글자 너비에 좌우 8씩 여백을 더한다.
