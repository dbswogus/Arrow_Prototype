# AGENTS — 협동 공방 확장

GAME_DESIGN.md와 현재 구현을 기준으로 작업한다. 한 화면 공유형 2인 로컬 협동을 유지한다.

## 유지하는 기준
순수 WebGL + 일반 JavaScript, 화면에 표시되는 canvas 하나, 공유 직교 카메라 하나, 외부 엔진/CDN/API/네트워크 로더 없음. Node/npm/Vite는 플레이에 필요하지 않다. 글자·버튼·조이스틱·미니게임도 오프스크린 2D canvas를 텍스처로 만들어 같은 WebGL canvas에 표시한다.

P1 WASD/F/G, P2 방향키/Enter/오른쪽 Shift. 태블릿은 각자 조이스틱/행동/놓기. 한 사람이 동시에 들 수 있는 물건은 하나. 기본 조이스틱 표시와 캔버스 토글을 유지한다. 빠른 상대 접근 충돌은 둘 다 0.7초 넘어짐·낙하·기상 후 1초 보호, 느린 접촉은 위치 분리한다.

공동 주문 한 건씩, 납기 45초. 가상 365일을 45초로 압축하여 날짜와 초를 함께 표시한다. 한 판 180초, 마지막 20초 새 주문 보충 중단. 실제 각궁 공예와 제작 기간을 그대로 재현하는 시스템이 아니다. 건조·뒤집기·품질 보너스도 게임용 축약 규칙이다.

## 작업 원칙
- src/game.js는 DOM/렌더링에 의존하지 않는 게임 모델이다. props와 benches를 충돌·근접 판정·표시에서 함께 사용한다.
- src/render.js는 직접 WebGL, src/controls.js는 포인터별 독립 입력, src/main.js는 캔버스 UI·합성 효과음·프레임 연결을 담당한다.
- 이동은 substep으로 계산한다. 포커스/가시성 이탈 시 일시 정지, 취소·캡처 상실·회전 시 입력 정리.
- 품질(0/25/50)과 추가 마감 시도 여부는 건네기/선반/낙하/회수/작업대 처리에서 보존해야 한다. 추가 마감 실패는 기존 품질을 낮추지 않는다.
- 기존 데이터는 archive에 보존한다. 다른 저장소 변경을 되돌리거나 자동 커밋하지 않는다.
- 테스트는 개발 도구이며 플레이 설치 요건이 아니다. 실제 브라우저·실물 태블릿을 검증하지 않았다면 통과했다고 주장하지 않는다.
- 새 외부 자산의 출처·라이선스를 기록한다. 사용자 제공 a/b 캐릭터의 라이선스는 별도 확인 대상이다.
