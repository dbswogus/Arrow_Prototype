# AGENTS — 각궁 8단계·30초 주문

GAME_DESIGN.md와 현재 구현을 기준으로 유지한다. 사용자가 제공한 전시 사진의 순서를 게임 작업대 네 개로 묶는다.

## 공통 기준
한 화면 공유형 2인 로컬 협동, 고정 직교 공방, WebGL canvas 하나. 순수 WebGL + 일반 JavaScript이며 외부 엔진/Three.js/CDN/API/네트워크 자산 요청/빌드를 사용하지 않는다. index.html의 일반 script로 오프라인 실행하도록 구성한다. Node는 개발 검사에만 사용한다.

P1 WASD/F/G, P2 방향키/Enter/오른쪽 Shift. 태블릿 독립 포인터 조이스틱/행동/놓기, PC도 조이스틱 기본 표시 및 숨기기 토글. 물건은 각자 하나, 바라보는 방향 앞에 표시. 바닥 드롭/회수, 마주 보고 건네기, 한 칸 전달 선반을 유지한다. 빠른 충돌은 둘 다 0.7초 넘어짐·낙하·기상 후 1초 보호, 느린 접촉은 위치 분리한다.

중앙 건조대·도구 보관대·좁은 지름길·넓은 통로는 물리 설비다. 이름표 배경은 실제 글자 크기에 맞춘다. 소리 토글 버튼/계절 연출/바닥 통로 글자/작업대 아래 안내 문구는 표시하지 않는다. 납품 효과음·포장·색종이·점수 팝업은 유지한다.

## 사진의 8단계와 게임의 4개 작업대
| 게임 작업대 | 전시 사진의 단계 | 게임 처리 시간 |
|---|---|---:|
| 몸체 | ① 재료 손질 → ② 활 몸체 만들기 | 3초 |
| 접합 | ③ 물소뿔 붙이기 → ④ 쇠심줄 올리기 | 4초 |
| 중앙 건조대 | ⑤ 건조하기 | 3초 |
| 마무리 | ⑥ 해궁하기 → ⑦ 화피단장 | 3초 |
| 출고 | ⑧ 각궁 완성 | 즉시 |

몸체 재료를 몸체 작업대에 넣고 활 몸체를 회수한다. 접합대에 활 몸체를 먼저 넣고 ‘접합 재료 묶음’을 추가하면 접합 작업이 시작된다. 이 묶음은 뿔·심줄의 운반을 단순화한 게임용 재료이며 실제 공정에서 두 재료를 한 번에 처리한다는 뜻이 아니다. 결합 몸체를 중앙 건조대에서 건조하고, 건조 몸체를 마무리대에서 처리하여 완성 활을 출고한다.

각 작업은 idle/processing/ready. 자동 처리 합계는 13초이며 운반·투입·회수 시간은 별도다. 처리 중 이름표는 현재 단계만 짧게 표시한다. 몸체는 1.5초씩 두 단계, 접합은 2초씩 두 단계, 마무리는 1.5초씩 두 단계로 나누어 표시한다. 이는 실제 각 공정 소요 시간 비율을 재현하지 않는다.

## 품질과 시간 선택
기본 제작은 자동으로 해궁과 화피단장까지 진행하여 100점 활을 만든다. 두 보너스는 정밀 작업을 선택하는 게임용 규칙이다.
- 해궁 균형 보너스: 마무리 작업 시작 후 첫 1.5초의 해궁 단계에서, 빈손으로 초록 구간에 맞춰 행동한다. 한 번 성공하면 +25. 실패하거나 놓쳐도 자동 마무리는 계속된다. 추가 대기 시간을 만들지 않는다.
- 추가 화피단장: 완성 활을 들고 마무리대에서 다시 행동한다. 움직이는 표시를 초록 구간에 맞춰 다시 행동하면 +25. 물건당 한 번, 최대 3초. 실패·시간 초과에도 기존 품질은 유지한다.
- 두 보너스 모두 성공하면 150점, 하나만 성공하면 125점, 생략하면 100점. 품질과 추가 시도 여부는 건네기/선반/낙하/회수에서 보존한다.

건조대는 3초 자동 건조만 한다. 이전 버전의 건조 중 뒤집기는 제거했다.

## 유지·검증 원칙
- 공동 주문 한 건, 기한 30초, 한 판 180초, 마지막 20초 주문 보충 중단. 플레이 HUD는 실제 게임 초만 표시한다. 가상의 남은 날짜 계산은 사용하지 않는다.
- 실제 제작이 약 1년에 걸리는 사례와 13초 게임 공정을 구분한다. 역사적 공법/시간을 그대로 재현했다고 주장하지 않는다.
- 순수 모델 game.js, 직접 WebGL render.js, 포인터/키 controls.js, 상태·UI·합성 효과음 main.js를 분리한다.
- 캐릭터/물건 품질과 추가 화피단장 시도 여부를 보관·인계·낙하에서 유지한다. 타이밍 보너스의 중복 획득을 허용하지 않는다.
- 이전 소스와 문서는 archive/before-eight-stages에 보존했다. 다른 저장소 변경을 되돌리거나 자동 커밋하지 않는다.
- 실제 GPU/브라우저/태블릿 검증을 수행하지 않았다면 통과라고 기록하지 않는다. 자동/모의 검사와 소프트웨어 미리보기는 별도로 표시한다.
