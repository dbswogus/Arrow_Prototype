# 각궁 공방 대소동

단일 WebGL 캔버스에서 실행하는 1인용 3D 제작 게임 프로토타입.

## 실행
Python이 설치되어 있다면 이 폴더에서 `python -m http.server 8000` 실행 후 http://localhost:8000 접속. Node/Vite/npm 설치 불필요. ES module 때문에 index.html 더블 클릭(file://) 실행은 지원하지 않습니다. Three.js CDN 접근을 위해 인터넷이 필요합니다.

## 조작
- 왼쪽 아래 영역에서 드래그 또는 WASD: 이동
- 오른쪽 행동 버튼 또는 Space: 근접 대상 집기/투입/납품
- 내려놓기: 바닥에 물건 보관. 빈손으로 근처에서 행동하여 회수
- 몸체 재료 → 몸체 작업대 5초 → 활 몸체와 뿔을 결합대에 순서대로 투입 6초 → 마감대 4초 → 출고
- 180초, 납품당 100점, 동시 주문 2개. 만료 감점 없음. 마지막 20초에는 주문 보충 중단.

## 구조
src/main.js: 렌더링/게임 연결, scene.js: 순수 게임 상태, player.js: 이동/충돌, workstations.js: 배치/근접 판정, input.js: Pointer/키보드, ui.js: WebGL UI, text.js: 오프스크린 텍스처, orders.js: 게임 상태 공개 모듈.

모든 표시 요소는 WebGL canvas 하나에 렌더링합니다. 텍스트용 2D canvas는 DOM에 추가하지 않습니다. TITLE → TUTORIAL → PLAYING → RESULT 상태를 사용합니다. 실제 제작 공법/시간을 재현하지 않는 창작 규칙입니다.

## 검증과 남은 작업
제작/납품/주문 만료/종료/재시작 로직 테스트 통과. HTTP 서버와 실제 브라우저에서 시작/튜토리얼/플레이 화면 및 오류 없는 렌더링 확인. 실제 태블릿 터치, 어린이 사용성, 전체 판 수동 납품, 성능 계측은 미완료입니다. 소리, 캐릭터 동작, 실제 전시자료 고증 검토는 후속 작업입니다.
