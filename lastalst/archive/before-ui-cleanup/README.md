# 각궁 공방 대소동 — 협동 맵 확장판

폴더를 통째로 풀고 **index.html**을 Chrome/Edge에서 엽니다. 설치·빌드·Node/npm/Vite·외부 엔진·인터넷이 필요 없도록 구성했습니다. WebGL 사용이 가능한 브라우저가 필요합니다. 실제 브라우저 실행은 이번 작업에서 검증하지 못했습니다.

## 조작
P1 WASD 이동 / F 행동 / G 놓기. P2 방향키 이동 / Enter 행동 / 오른쪽 Shift 놓기. 태블릿은 각자 조이스틱/행동/놓기. PC에서도 조이스틱이 기본 표시되며 상단 버튼으로 숨길 수 있습니다.

## 이번에 할 수 있는 일
- 중앙 건조대와 도구 보관대 사이 지름길, 왼쪽 넓은 우회로 중 동선을 선택합니다.
- 가까이 마주 보고 행동하여 빈손인 파트너에게 물건을 건넵니다.
- 전달 선반 양쪽에서 물건을 넣고 꺼냅니다. 한 칸만 있으니 파트너와 나누어 사용하세요.
- 결합 몸체를 중앙 건조대에 걸고 6초 동안 기다립니다. 노란 표시가 켜진 2~4.5초 사이에 빈손으로 행동하면 품질 +25입니다. 놓쳐도 기본 품질로 완성됩니다.
- 건조 몸체를 마감 4초 후 출고하면 100점(정성 건조는 125점). 완성 활을 들고 마감대에서 다시 행동하면 추가 마감을 선택할 수 있습니다. 초록 구간에 표시가 오면 다시 행동하여 +25, 최고 150점입니다. 실패해도 기존 품질을 잃지 않습니다.
- 납품 시 포장/점수/색종이/합성 효과음이 나오고 주문 달력에 따라 사계절 분위기가 변합니다. 소리는 상단에서 끌 수 있습니다.
- 결과에서 최고 품질·연속 납품·건네기 기록을 확인합니다.

몸체 가공 5초 → 뿔 결합 6초 → 건조 6초 → 마감 4초 → 출고. 공동 주문은 한 건씩 45초, 한 판은 180초입니다. 실제 공예와 제작 기간·건조 방법을 그대로 재현하지 않은 게임용 규칙입니다.

## 보존과 검증
직전 전달한 1년 주문 수정본을 기반으로 확장했습니다. 로컬 Arrow_Prototype/ffff의 파일도 읽어 확인했으나 해당 폴더는 쓰기 허용 범위 밖이므로 직접 변경하지 않았습니다. 확장 전 소스·문서는 archive/before-coop-expansion에 보존했습니다. 실제 GPU/브라우저/태블릿 실행은 미검증입니다. 자동 검사와 소프트웨어 미리보기의 범위는 docs/coop-expansion.md 참조.

tests/logic.cjs, year-order.cjs, input.cjs, ui.cjs는 개발 검사입니다. Node는 검사에만 사용하며 게임 사용자에게 필요하지 않습니다.
