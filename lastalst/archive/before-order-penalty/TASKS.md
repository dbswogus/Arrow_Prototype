## 5작업대 배치 변경
오른쪽 아래 (x=7.3, z=1.0)에 해궁대를 추가했다. 활을 받치는 틀과 청록 작업면을 사용하고, 기존 오른쪽 위 작업대는 붓·겉면 재료를 둔 화피단장대 전용으로 분리했다. 해궁 완료품 ‘균형 잡은 활’을 실제로 옮겨야 하며 곧바로 출고할 수 없다.

전달 선반의 보관 기능은 유지하되 지도 위 이름표는 표시하지 않는다. 가까이 있을 때는 하단 행동 안내만 ‘맡기기 / 꺼내기’로 표시한다. 지름길 옆 도구 보관대의 길이는 3.4→4.2로 늘리고 실제 충돌과 그리기에 동일한 크기를 사용한다. P2 시작 위치를 새 해궁대와 겹치지 않도록 옮겼다. 30초 주문 기한과 기존 협동/품질/입력/화면 정리 요구는 유지한다.

## 분업과 공정 체험 개정
방을 가로 18→24, 세로 12로 넓혔다. 왼쪽은 몸체/접합 재료 창고와 몸체·접합대, 오른쪽은 해궁·화피단장·출고다. 중앙의 이름 없는 선반은 양쪽에서 넣고 꺼내며, 좁은 위쪽 통로 또는 넓은 아래쪽 우회로로 직접 이동할 수도 있다. 특정 플레이어만 사용할 수 있는 작업대나 강제 역할 제한은 없다. 중앙 건조대는 양쪽에서 접근할 수 있다.

왼쪽에서 접합한 몸체를 중앙 선반에 넘기고 다음 활을 준비하면, 오른쪽 플레이어는 이어받아 건조·해궁·화피단장·출고를 진행할 수 있다. 결과에 함께 만든 활과 선반 인계를 기록한다. 이 기록은 재료의 참여자 정보를 운반·보관·작업대 처리에서 보존하여 계산하며 학습 성취를 뜻하지 않는다.

물건 도형은 나무 몸체 → 어두운 뿔 층 → 밝은 심줄 층과 결합 고리 → 건조 고리 → 해궁으로 펴진 활 → 화피로 감싼 완성 활로 바뀐다. 작업 중에도 재료가 붙고 모양이 펴지고 겉면이 입혀지는 진행을 표시한다. 색·고정띠·곡선 변화는 게임용 식별 표현이며 실제 치수·재료 변형·공법을 정밀 재현하지 않는다.

각 공정의 첫 유효 작업에서만 짧은 한 문장 설명을 표시한다. 한 번에 카드 하나, 4초 후 자동 사라짐, 동시에 시작하면 순서대로 표시, 한 판에 같은 설명은 한 번만 나온다. 게임 시간과 입력을 멈추지 않으며 재시작하면 다시 표시한다. 설명 문구의 출처와 검증 범위는 docs/team-learning.md에 기록했다.
