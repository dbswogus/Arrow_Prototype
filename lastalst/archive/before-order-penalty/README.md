# 각궁 공방 대소동 — 8단계·30초 주문판

압축을 풀고 **index.html**을 엽니다. 순수 WebGL과 일반 JavaScript로, 외부 엔진/CDN/인터넷/Node/npm/Vite 없이 실행하도록 구성했습니다. 실제 브라우저 실행은 이번 작업에서 검증하지 못했습니다.

## 조작
P1 WASD / F 행동 / G 놓기. P2 방향키 / Enter 행동 / 오른쪽 Shift 놓기. 태블릿은 각자 조이스틱/행동/놓기. PC에서도 조이스틱을 표시하며 상단에서 숨길 수 있습니다.

## 사진의 8단계와 게임의 5개 작업대
| 게임 작업대 | 전시 사진의 단계 | 게임 처리 시간 |
|---|---|---:|
| 몸체 | ① 재료 손질 → ② 활 몸체 만들기 | 3초 |
| 접합 | ③ 물소뿔 붙이기 → ④ 쇠심줄 올리기 | 4초 |
| 중앙 건조대 | ⑤ 건조하기 | 3초 |
| 해궁 | ⑥ 해궁하기 | 2초 |
| 화피단장 | ⑦ 화피단장 | 2초 |
| 출고 | ⑧ 각궁 완성 | 즉시 |

몸체 재료를 몸체 작업대에 넣고 활 몸체를 회수한다. 접합대에 활 몸체를 먼저 넣고 ‘접합 재료 묶음’을 추가하면 접합 작업이 시작된다. 이 묶음은 뿔·심줄의 운반을 단순화한 게임용 재료이며 실제 공정에서 두 재료를 한 번에 처리한다는 뜻이 아니다. 결합 몸체를 중앙 건조대에서 건조하고, 건조 몸체를 오른쪽 아래 해궁대에서 처리하여 균형 잡은 활을 꺼낸다. 이를 오른쪽 위 화피단장대에서 처리하여 완성 활을 출고한다.

각 작업은 idle/processing/ready. 자동 처리 합계는 14초이며 운반·투입·회수 시간은 별도다. 처리 중 이름표는 현재 단계만 짧게 표시한다. 몸체는 1.5초씩 두 단계, 접합은 2초씩 두 단계, 해궁과 화피단장은 서로 다른 작업대에서 각각 2초씩 처리한다. 이는 실제 각 공정 소요 시간 비율을 재현하지 않는다.

## 품질과 시간 선택
기본 제작은 자동으로 해궁과 화피단장까지 진행하여 100점 활을 만든다. 두 보너스는 정밀 작업을 선택하는 게임용 규칙이다.
- 해궁 균형 보너스: 해궁대의 2초 작업 중, 빈손으로 초록 구간에 맞춰 행동한다. 한 번 성공하면 +25. 실패하거나 놓쳐도 자동 해궁은 계속된다. 추가 대기 시간을 만들지 않는다.
- 추가 화피단장: 완성 활을 들고 화피단장대에서 다시 행동한다. 움직이는 표시를 초록 구간에 맞춰 다시 행동하면 +25. 물건당 한 번, 최대 3초. 실패·시간 초과에도 기존 품질은 유지한다.
- 두 보너스 모두 성공하면 150점, 하나만 성공하면 125점, 생략하면 100점. 품질과 추가 시도 여부는 건네기/선반/낙하/회수에서 보존한다.

건조대는 3초 자동 건조만 한다. 이전 버전의 건조 중 뒤집기는 제거했다.

주문 한 건의 기한은 **30초**, 한 판은 180초입니다. 게임 방법은 세 페이지로 나누어 설명합니다. Enter 또는 다음 버튼으로 넘깁니다. 맵의 전달 선반·건네기·낙하·방향 운반을 유지했고, 소리 버튼·계절·통로 글자는 표시하지 않습니다.

## 검증과 보존
자동 시나리오 비교에서 150점 활 3개를 단독 83.26초, 선반 분업 55.19초에 납품했습니다. 입력 지연과 실수가 없는 자동 검사이며 실제 사용자의 플레이 기록은 아닙니다. 모델/입력/UI/구문 검사를 통과했으며 실제 GPU·브라우저·태블릿은 미검증입니다.

실제 로컬 Arrow_Prototype/Co_op_arrow_made를 읽어 기반으로 사용했습니다. 해당 원본 폴더는 쓰기 허용 범위 밖이므로 직접 변경하지 않았습니다. 수정 전 파일은 archive/before-team-learning에 보존했습니다. 상세 기록은 docs/eight-stages.md 참조.

## 5작업대 배치 변경
오른쪽 아래 (x=7.3, z=1.0)에 해궁대를 추가했다. 활을 받치는 틀과 청록 작업면을 사용하고, 기존 오른쪽 위 작업대는 붓·겉면 재료를 둔 화피단장대 전용으로 분리했다. 해궁 완료품 ‘균형 잡은 활’을 실제로 옮겨야 하며 곧바로 출고할 수 없다.

전달 선반의 보관 기능은 유지하되 지도 위 이름표는 표시하지 않는다. 가까이 있을 때는 하단 행동 안내만 ‘맡기기 / 꺼내기’로 표시한다. 지름길 옆 도구 보관대의 길이는 3.4→4.2로 늘리고 실제 충돌과 그리기에 동일한 크기를 사용한다. P2 시작 위치를 새 해궁대와 겹치지 않도록 옮겼다. 30초 주문 기한과 기존 협동/품질/입력/화면 정리 요구는 유지한다.

## 분업과 공정 체험 개정
방을 가로 18→24, 세로 12로 넓혔다. 왼쪽은 몸체/접합 재료 창고와 몸체·접합대, 오른쪽은 해궁·화피단장·출고다. 중앙의 이름 없는 선반은 양쪽에서 넣고 꺼내며, 좁은 위쪽 통로 또는 넓은 아래쪽 우회로로 직접 이동할 수도 있다. 특정 플레이어만 사용할 수 있는 작업대나 강제 역할 제한은 없다. 중앙 건조대는 양쪽에서 접근할 수 있다.

왼쪽에서 접합한 몸체를 중앙 선반에 넘기고 다음 활을 준비하면, 오른쪽 플레이어는 이어받아 건조·해궁·화피단장·출고를 진행할 수 있다. 결과에 함께 만든 활과 선반 인계를 기록한다. 이 기록은 재료의 참여자 정보를 운반·보관·작업대 처리에서 보존하여 계산하며 학습 성취를 뜻하지 않는다.

물건 도형은 나무 몸체 → 어두운 뿔 층 → 밝은 심줄 층과 결합 고리 → 건조 고리 → 해궁으로 펴진 활 → 화피로 감싼 완성 활로 바뀐다. 작업 중에도 재료가 붙고 모양이 펴지고 겉면이 입혀지는 진행을 표시한다. 색·고정띠·곡선 변화는 게임용 식별 표현이며 실제 치수·재료 변형·공법을 정밀 재현하지 않는다.

각 공정의 첫 유효 작업에서만 짧은 한 문장 설명을 표시한다. 한 번에 카드 하나, 4초 후 자동 사라짐, 동시에 시작하면 순서대로 표시, 한 판에 같은 설명은 한 번만 나온다. 게임 시간과 입력을 멈추지 않으며 재시작하면 다시 표시한다. 설명 문구의 출처와 검증 범위는 docs/team-learning.md에 기록했다.

30초 주문·180초 판·5개 공정 작업대·14초 자동 처리·기존 보너스/충돌/입력/화면 정리를 유지했다. 검증은 자동·모의 환경과 소프트웨어 미리보기까지이며 실제 재미·학습 효과·브라우저·태블릿은 확인하지 않았다.
