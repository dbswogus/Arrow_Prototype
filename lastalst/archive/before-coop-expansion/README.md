# 각궁 공방 대소동 — 1년 주문 수정본

압축을 풀고 index.html을 열어 실행합니다. 외부 엔진/인터넷/Node/npm/Vite 없이 일반 script와 내장 캐릭터 데이터로 동작하도록 구성했습니다.

- P1 WASD / F 행동 / G 놓기. P2 방향키 / Enter 행동 / 오른쪽 Shift 놓기.
- PC·태블릿 모두 조이스틱 표시, 화면 버튼으로 숨기기/보기 전환.
- 물건은 캐릭터가 바라보는 방향 앞에 들고 함께 회전합니다. 뒤쪽을 바라볼 때는 캐릭터가 물건을 가립니다.
- 공동 주문은 **한 건씩**, 기한은 **45초**. 게임 속 1년(365일)을 45초로 압축해 남은 날짜와 초를 함께 표시합니다. 주문을 완료/교체하면 다음 주문의 1년이 시작됩니다. 동시에 두 번째 주문을 표시하지 않습니다.
- 한 판 180초, 납품 100점, 마지막 20초 주문 보충 중단. 작업은 5/6/4초로 유지합니다.
- 창고와 작업대를 공방 가장자리 2행 3열로 배치해 가운데 통로를 넓혔습니다.

실제 제작에 약 1년이 걸리는 사례를 소재로 한 게임용 시간 압축입니다. 실제 공정별 기간을 비례 재현하거나 모든 각궁이 정확히 365일 걸린다고 단정하지 않습니다. [제작 기간이 약 1년인 사례를 소개한 연합뉴스 인터뷰](https://www.yna.co.kr/view/AKR20100312160400063).
