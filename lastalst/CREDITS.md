# 출처와 자산

현재 실행 코드는 외부 엔진/라이브러리/이미지/폰트 다운로드/모델/사운드를 사용하지 않는다. 공방·캐릭터·물건은 코드로 생성한 도형, 문자는 운영체제 기본 폰트로 오프스크린 canvas에서 그린 텍스처다.

각궁 공예를 소재로 한 창작 협동 게임이다. 실제 제작 공법·시간을 설명하는 검증된 사료는 이번 구현에 포함하지 않았다. 향후 박물관 검토 자료를 확보하면 정확한 출처·사용 허락·라이선스를 여기에 기록한다. 기존 버전과 당시 출처 문서는 archive/before-coop-20261105에 보존되어 있다.

## a/b 캐릭터 추가
사용자가 제공한 GLB format/character-a.glb, character-b.glb 및 Textures/texture-a.png, texture-b.png를 사용합니다. 메시와 대기/걷기 포즈, 텍스처를 src/characters.js로 변환해 내장했습니다. 제작자와 라이선스 문서는 제공 파일에서 확인하지 못했습니다. 자세한 내용은 docs/characters.md를 참조하세요.

## 협동 맵 확장
건조대/전달 선반/도구 보관대와 UI/납품 입자는 자체 생성 도형입니다. 납품·계절 효과음은 브라우저 Web Audio로 합성하며 외부 음원을 사용하지 않습니다. a/b 캐릭터와 원본 텍스처의 출처 및 라이선스 확인 대상은 이전 기록을 유지합니다.


화면 정리판에서는 계절 연출과 계절 합성음을 제거했습니다. 납품 합성 효과음만 유지합니다.

## 8단계 공정 반영
공정 명칭과 순서는 사용자가 대화에 첨부한 각궁 제작과정 전시 사진을 참조했습니다. 사진 자체를 새 게임 자산으로 포함하지 않았습니다. 접합 재료 묶음과 공정 시간 및 타이밍 보너스는 게임용 축약 규칙입니다.


## 분업·공정 체험 개정
넓어진 공방·재료 층·고리·해궁·화피 도형과 짧은 설명 UI는 자체 구현했다. 새로운 외부 이미지/모델/음원/폰트를 추가하지 않았다. 공예 설명은 사용자 전시 사진과 docs/team-learning.md에 링크한 국가유산진흥원 및 장인 인터뷰를 참고한 짧은 재서술이다. 외부 웹페이지·사진을 게임에 복제하거나 실행 중 불러오지 않는다. 기존 a/b 캐릭터와 제공 텍스처의 출처·라이선스 확인 대상은 유지한다.
