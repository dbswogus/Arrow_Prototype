# 국궁 한 순 대결 · 클래스 분리 버전

## 실행

ZIP 전체를 압축 해제한 뒤 `index.html`을 Chrome 또는 Edge에서 엽니다. **Node.js, npm, Vite 및 빌드가 필요 없습니다.** `index.html`, `css/`, `js/`를 같은 폴더 구조로 유지하세요. HTML만 따로 옮기면 실행되지 않습니다.

Three.js 0.180.0을 jsDelivr에서 가져오므로 인터넷이 필요합니다. 완전한 오프라인 버전은 아닙니다. 태블릿에서 파일 미리보기 앱이 JavaScript를 실행하지 않는다면 HTML을 브라우저로 열거나 전체 폴더를 정적 웹 서버로 제공하세요.

## 이번 변경

- 별도 취소 버튼을 제거했습니다. 발사 버튼을 누르다가 버튼 밖으로 끌면 즉시 취소되며, 다시 안으로 돌아와도 발사되지 않습니다. 새로 눌러야 충전됩니다. 조준과 남은 화살은 유지됩니다. 키보드 충전 중에는 Escape로 취소합니다.

- 발사 버튼을 화면 아래 가운데로 이동하고 하단 안내·설정 버튼과 공간을 나눴습니다.
- 드래그 대신 꾹 누르는 동안 충전하고 손을 떼면 발사합니다. 약 1초에 최대 세기가 되며, 계속 누르고 있어도 자동 발사하지 않습니다.
- 버튼과 HUD에 충전량을 표시합니다. 마우스·터치·키보드 모두 누른 시간으로 세기를 정합니다.

- 커서 위치를 카메라의 원근 투영으로 변환하여 화면의 조준점과 일치시켰습니다. 이전의 고정 각도 범위와 별도 표시 계산을 제거했습니다.
- 클릭·터치로 조준을 고정합니다. 당김 버튼으로 마우스를 이동해도 선택한 각도가 바뀌지 않습니다. 다시 화면을 클릭하거나 드래그하면 재조준합니다.
- 내 차례 시작 시 카메라를 조준 시점으로 복귀시켜 이전 화살 추적 시점으로 좌표가 계산되지 않도록 했습니다.

- 연습을 제거했습니다. 대결 시작 버튼을 누르면 즉시 기록 경기를 시작합니다.
- NPC는 한 명이며 나와 교대로 각 5발, 총 10발을 쏩니다.
- 상하좌우 조준이 가능합니다. 화면 위쪽은 높은 각도, 아래쪽은 낮은 각도입니다.
- 발사 각도와 세기를 분리했습니다. 각도를 정한 뒤 별도의 당김 버튼으로 세기를 정합니다.
- 바람 가속도 계수를 4.8에서 3.8로 약 21% 줄였습니다. 화면의 풍향과 실제 이동 방향은 유지합니다.
- HTML에는 화면 구조와 파일 참조만 남기고 게임 진행·물리·입력·장면·카메라·UI를 클래스별 JavaScript 파일로 분리했습니다. 자세한 구조는 ARCHITECTURE.md에 있습니다.

## 조작

1. 원하는 화면 위치를 클릭하거나 터치·드래그하고 놓아 상하좌우 조준을 고정합니다. 조준점은 커서·손가락 위치에 표시됩니다.
2. 아래 가운데 **꾹 눌러 발사** 버튼을 누르고 기다립니다. 약 1초면 최대 세기입니다.
3. 원하는 세기에서 손을 떼면 발사합니다. 충전 중에는 각도가 고정됩니다.

화면에서 조준만 하고 손을 떼는 동작은 발사하지 않습니다. 고정 후에는 당김 버튼으로 마우스를 옮겨도 각도가 유지됩니다. 0.18초 미만으로 짧게 누르거나 누른 채 버튼 밖으로 끌면 취소됩니다. 마우스·터치 모두 동일합니다. 키보드는 발사 버튼에 초점을 맞추고 Enter/Space를 꾹 눌러 충전하고 키를 놓아 발사합니다. 창 포커스를 잃거나 터치가 취소되면 충전도 취소됩니다.

HUD에 높이 각도와 당김 정도를 표시합니다. 조준점은 발사 방향이며 중력·바람을 미리 보정한 탄착점이 아닙니다. 다음 차례에도 선택한 각도를 유지합니다. `카메라: 추적` 버튼으로 고정 과녁 카메라를 선택할 수 있습니다.

과녁 어디든 관중(O), 빗나가면 불중(X)이며 중심부 점수는 없습니다. 동점은 공동 순위, 5중은 몰기입니다. 결과 화면에서 다시 시작할 수 있습니다.

## 검증

JavaScript 전체 구문 검사와 자동 테스트 **22개 통과**. 상하 각도·세기 독립, 풍향, 바람 보정, 충돌, 교대·순위, 터치·당김 분리, 취소·입력 차단, 실제 Game 클래스의 10발 진행과 재시작을 확인했습니다. 가로·세로·태블릿·와이드 화면 비율에서 커서와 조준점의 좌표를 격자로 확인했고, 독립적인 원근 투영 공식 비교 및 조준 고정도 검증했습니다. 물리와 경기 테스트는 화면 객체를 대체한 상태에서 실행했습니다.

실제 WebGL 화면과 태블릿 기기에서는 검증하지 못했습니다. 사용 중인 브라우저 자동화 도구가 로컬 파일 열기를 차단하므로 시각적 결과·기기 성능·CDN 로딩은 미검증입니다.

개발자용 테스트는 `node tests/run.cjs`입니다. 이 명령은 선택 사항이며 **게임 실행에는 Node.js가 필요 없습니다.**

## 기획과 남은 작업

AGENTS.md, GAME_DESIGN.md, TASKS.md는 최초 기획을 보존한 문서입니다. 이후 사용자 요청으로 Node/Vite 제거, NPC 한 명, 연습 제거, 상하 조준을 적용했습니다. 현재 실행·조작은 이 README를 따릅니다.

2인 한 순 대결, 공동 순위, 사거리와 탄도는 체험용 축약이며 공식 경기규칙의 완전한 재현이 아닙니다. 고증 검수, 음향, 고품질 모델과 실제 태블릿 조작감 검증은 후속 작업입니다.
