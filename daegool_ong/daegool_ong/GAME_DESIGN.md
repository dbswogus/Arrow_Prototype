# 데굴데굴 옹기: 내 자리로 돌아가는 길

> 개정: 세 맵의 실루엣·동선·장식을 구분하고, 옹기는 눈 없는 기본 외형 사용. 선택 화면의 물리 규칙 설명 문구 삭제.

## 1. 프로젝트 개요

부천시박물관 옹기 소장품을 소재로 한 초등학생용 태블릿 물리 퍼즐이다. 3D 탑뷰 고정 카메라와 네 방향 기울이기를 사용하고, 목표 체험 시간은 3~5분이다. 속도 조절과 함정 회피로 굽은 길을 건넌다.

## 2. 스토리와 단계 순서

개관 5분 전, 전시 준비 수레에서 내려온 작은 옹기가 공방에서 눈을 뜬다. 자신의 이름표가 있는 전시대로 돌아가기 위해 공방 → 가마 앞 → 전시실을 지난다. 마지막 공간은 항상 전시실이며, 자신의 전시대에 도착하면 이야기를 마친다.

시작에 세 장면을 보여주고 각 단계 입구에서 목표를 설명한다. 이야기 속 5분은 실제 제한 시간이 아니다. 복층 공간과 동선, 사건은 창작이며 실제 박물관 구조나 소장품 이력으로 안내하지 않는다.

## 3. 확정 변경사항

| 항목 | 현재 결정 |
|---|---|
| 안전 지점 | 속도나 정지 여부와 관계없이 몸체가 초록 판에 닿으면 저장 |
| 화면 표기 | 왼쪽 위 TOP VIEW 삭제 |
| 가장자리 | 이미지에 표시한 형태처럼 꺾이는 모서리 부근에만 짧은 벽 유지. 나머지는 벽과 충돌 판정 제거 |
| 단계 수 | 점프·복층 운반 통로 삭제, 공방·가마 앞·전시실 총 세 단계 |
| 최종 단계 | 전시실을 3단계로 유지 |
| 점프 | 사용하지 않음 |

## 4. 조작과 물리

- 네 방향 버튼을 누르는 동안 해당 축의 기울기를 증가시킨다. 손을 놓으면 각도를 유지한다.
- 두 축의 기울기 크기를 합쳐 최대 25도로 제한한다. 반대 입력은 해당 축에서 상쇄한다.
- 기울어진 바닥의 중력 성분으로 가속하며 관성을 유지한다. 반대 기울기로 감속한다.
- 자유 위치·속도로 이동하고, 낮은 벽과 원형 몸체가 충돌한다. 길 중앙으로 자동 이동시키지 않는다.
- 점프 기믹은 삭제한다. 벽 없는 가장자리에서는 바닥 이탈과 낙하가 발생한다.

## 5. 서로 다른 세 맵

### 1단계 — 공방: 작업 마당 사이의 지그재그

왼쪽 위에서 출발해 작업대 사이를 돌아 오른쪽 아래 출구로 이동한다. 중간에 위·아래 방향이 바뀌는 지그재그 경로와 넓은 원형 작업 마당을 조합한다. 길 폭은 2.8이고 주요 마당 반지름은 1.8이다. 옹기 세 개가 놓인 작업대 장식은 제거한다. 구멍은 세 곳, 접촉 저장은 세 곳이다.

### 2단계 — 가마 앞: 세 개의 나무 다리

왼쪽 아래에서 출발해 위·아래로 긴 세 다리를 번갈아 건너 오른쪽 위에 도착한다. 두 커다란 가마를 다리 사이 빈 공간에 배치하고, 길 위 나무판 무늬로 다리임을 표현한다. 폭 2.3의 긴 직선 다리와 끝마당을 조합한다. 구멍 한 곳과 왕복 도구 두 개가 있으며, 끝마당 세 곳에서 저장할 수 있다.

### 3단계 — 전시실: 바깥 통로에서 중앙으로

왼쪽 아래에서 위쪽으로 진행하고, 전시장 상단과 오른쪽을 크게 돌아 아래쪽에서 중앙 전시대로 들어간다. 출구가 외곽 끝이 아닌 중앙에 있다. 폭은 2.65이며 최종 전시대에는 반지름 1.75의 여유 공간이 있다. 양쪽 진열장과 외곽 기둥을 배치한다. 구멍 두 곳, 왕복 도구 하나, 금 간 판 두 개와 저장 지점 세 곳을 둔다.

모든 맵은 기존처럼 꺾이는 일부 모서리에만 짧은 벽을 두고 나머지 외곽은 열어 둔다. 각각의 실제 바닥 형상, 동선, 출발·도착 위치, 장식, 장애물 배치를 구분한다.

## 6. 저장·실패·완료

초록 판과 원형 몸체의 접촉으로 저장한다. 속도 조건과 대기 조건은 없다. 기록에는 위치와 층을 함께 저장하며, 더 뒤의 안전 지점이 이전 지점을 덮어쓴다.

구멍·왕복 도구 접촉·무너진 발판은 실패를 일으킨다. 낙하 연출 후 마지막 안전 지점으로 복귀한다. 속도·기울기·입력·점프 상태와 금 간 발판 상태를 초기화한다. 왕복 도구에만 1.5초 복귀 보호 시간을 적용한다. 재도전 횟수 제한은 없다.

각 단계의 최종 초록 목표(1.7×1.7)에 옹기 몸체가 닿으면 속도·대기 조건 없이 즉시 다음 단계 설명으로 이동한다. 마지막 전시실은 바로 결과 화면으로 이동한다.

## 8. UI와 실행

시작 화면은 옹기 한 개와 바닥 그림자를 사용해 겹침을 없앤다. 플레이 화면의 왼쪽 제목·단계 설명, 목표 상자, 속도 창, 하단 저장·제동 안내 문구는 표시하지 않는다. 단계 표시·재도전 상태·방향 버튼·기울기 표시와 필요한 임시 안내만 제공한다. 배경은 화면 전체를 채우고, 게임과 UI의 비율 및 터치 좌표는 보존한다.


시작 → 선택 → 조작 안내 → 이야기 세 장면 → 단계 설명·플레이 세 번 → 완료 순서다. 모든 화면 요소를 단일 WebGL canvas 안에 표시한다. 세 단계 진행, 기울기, 저장 상태와 재도전 횟수를 안내한다.

현재 시제품은 기본 WebGL을 사용하는 단일 HTML이며 npm·Vite·CDN·원격 글꼴 없이 오프라인 실행한다. 외부 다운로드 제한으로 Three.js를 포함하지 못했으며, Three.js 로컬 포함은 미충족 상태로 남긴다.

## 9. 우선순위와 검증

1. 모서리에만 짧은 벽을 렌더링하고 같은 조각 데이터로 충돌 처리.
2. 나머지 모든 외곽에서 보이지 않는 충돌 벽도 제거.
3. 점프 단계와 관련 안내 삭제, 공방·가마 앞·전시실 순서 확인.
4. 접촉 저장과 구멍·도구·붕괴·열린 가장자리의 실패 확인.
5. 함정을 활성화한 세 단계 통과 가능성.
6. 실제 화면·태블릿·초등학생 체험으로 모서리 벽 위치와 난이도 조정.

## 10. 미확정사항

실제 소장품 자료와 사진 권리, 현장 태블릿 성능과 터치 검증, 초등학생의 체험 시간 및 난이도, Three.js 전환과 최종 배포 방식은 확인이 필요하다. 자동 검증과 실제 사용 검증을 구분한다.

## 자막과 배경 정리

플레이 중 임시 안내 자막은 상단 왼쪽(기준 좌표 x=64, y=42)에 배치하고 오른쪽 단계 표시와 겹치지 않게 한다. 배경 위쪽에 줄지어 있던 직육면체 일곱 개는 모든 맵에서 제거한다.

## 조용한 복귀와 맵 확대

실패 시 팝업과 실패·복귀 자막을 표시하지 않고, 낙하 연출 후 저장 지점에 조용히 복귀한다. 기존 단계 표시와 재도전 횟수는 유지한다. 배경에 장식을 추가하지 않고 플레이 맵을 20% 확대하며 고정 카메라를 유지한다.

## 하단 조작과 단계 전환 개정

맵을 직전 버전보다 10% 축소한다. 방향 버튼은 하단에 왼쪽부터 ← ↑ / ↓ → 순서로 나눠 배치하고 기존 십자형 패널을 없앤다. 시작 화면의 기술 요약 배지와 경사·관성 홍보 문구를 삭제한다. 1단계 소개는 유지하고 2·3단계는 소개 화면·시작 자막 없이 바로 플레이한다.

## 조이스틱 조작 개정 — 이전 버튼 조작 규칙 대체

네 방향 터치 버튼을 제거하고 왼쪽 아래 단일 아날로그 조이스틱을 사용한다. 방향과 밀어낸 거리를 목표 기울기에 대응시키고 최대 기울기를 합산 18도로 제한한다. 12% 이내 작은 입력은 무시하고 나머지 구간을 연속적으로 정규화한다. 손을 놓으면 수평으로 복귀하고 감쇠를 높여 부드럽게 정지한다. 한 손가락만 조이스틱을 소유하며 터치 취소·캡처 해제·앱 전환·실패·단계 전환 시 입력을 초기화한다. 키보드 화살표는 보조 입력이다.

## 오른손 조이스틱 및 기존 물리 복원

조이스틱을 오른쪽 아래로 이동한다. 조이스틱은 기울기 변화 방향과 속도를 조절하며, 놓으면 현재 기울기를 그대로 유지한다. 수평 자동 복귀와 손을 놓았을 때의 추가 제동을 제거한다. 기존 합산 최대 25도, 일정한 기본 마찰을 사용한다. 터치 해제·취소 시 입력은 해제하되 각도는 자동으로 바꾸지 않는다. 이 규칙은 앞선 수평 복귀·추가 감속·18도 규칙을 대체한다.

## 선택·설명 화면 확장

세 가지 선택지를 여섯 가지로 확장한다. 왼쪽은 3열 2행의 3D 옹기 카드, 오른쪽은 선택한 옹기의 확대 모델·게임용 별명·형태 특징 두 문장·관찰 질문으로 구성한다. 카드를 누르면 설명이 즉시 바뀌며, 출발 버튼에 선택한 별명을 표시한다. 선택은 이야기·플레이·결과에 유지된다.

게임용 별명은 동글옹기·길쭉옹기·납작옹기·꼬마옹기·목긴옹기·반듯옹기이다. 설명은 자체 제작 모델의 형태에 한정한다. 실제 소장품 명칭·용도·시대·사진·라이선스·허가는 확인 전임을 화면에 표시한다. 플레이어에게 캐릭터 간 물리 규칙을 설명하는 문구는 표시하지 않는다.

## 하단 중앙 조이스틱

조이스틱을 하단 중앙(800,850)으로 이동하고 기울기 표시를 하단 오른쪽으로 분리한다. 실제 입력 판정도 같은 중심 좌표를 사용한다. 기존 기울기 유지·기본 마찰과 선택·맵 규칙은 변경하지 않는다.

## 수평 복귀 재적용

조이스틱을 놓거나 중앙에 두면 두 축의 기울기가 부드럽게 0으로 복귀한다. 약 0.5초에 95% 복귀하고 미세 각도는 0으로 정리한다. 추가 감속은 넣지 않으며 기존 기본 마찰과 관성을 유지한다. 중앙 하단 조이스틱, 최대 25도, 맵과 함정은 유지한다. 수평 복귀·입력 중 기울이기·기존 마찰 유지 여부를 자동 확인했다. 실제 태블릿 조작감은 미검증이다. 이 내용은 앞선 기울기 유지 규칙을 대체한다.

## 수평 복귀 속도 완화

수평 복귀 시간을 직전 버전의 약 두 배로 늘린다. 약 1초에 95% 복귀하며, 조이스틱 입력과 마찰·관성은 유지한다.
