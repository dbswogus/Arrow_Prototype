# 맵 차별화 / 기본 옹기 버전 검증

## 통과

- 시작 화면 받침대와 작은 옹기, 공방의 세 옹기 작업대 제거 확인.
- 플레이 화면에서 표시 요청한 제목·목표·속도·하단 문구가 그려지지 않음 확인.
- 1600×900, 1920×1080, 1024×768에서 canvas가 전체 화면 크기를 사용하고 내부 비율이 유지됨 확인.
- 각 크기에서 화면의 방향 버튼과 변환된 터치 좌표가 일치함 확인.


- 공방의 역방향 지그재그, 가마 앞의 긴 세 다리, 전시실의 중앙 목적지가 서로 구분됨.
- 눈 메시·그리기·깜빡임 코드를 제거했음을 확인.
- 실제 화면 그리기에 사용된 모든 문구에서 물리 규칙 설명이 제거됨.

- JavaScript 구문 검사와 대체 그래픽 환경의 모든 화면 호출.
- 맵이 공방·가마 앞·전시실 세 개이며 이전 점프 단계가 없음.
- 관련 점프 함수·발판·복층 이야기와 안내가 제거됨.
- 실제 렌더링되는 벽과 충돌 벽이 같은 짧은 벽 조각 데이터를 사용함.
- 모든 벽이 모서리 지정 구역 안에만 존재함. 각 맵의 전체 외곽 대비 벽이 남은 비율은 약 18.9 / 18.8 / 12.3%.
- 각 맵의 벽 없는 직선 가장자리로 움직이면 실제 낙하·실패 발생.
- 남아 있는 짧은 벽은 실제 원형 플레이어와 충돌함.
- 높은 속도로 안전 지점 가장자리에 닿아도 저장되고 복귀 위치가 유지됨.
- 구멍·왕복 도구·금 간 발판의 실패 유지.
- 모든 함정을 활성화한 세 단계 전체 통과 및 전시실 마지막 배치.
- 두 축 기울이기, 합산 25도 제한, 반대 입력, 관성·경사별 가속 유지.
- 단일 표시 canvas와 오프라인 의존성 확인.

자동 제어는 모든 함정을 켠 상태에서 각 맵 약 33.6 / 37.9 / 38.1초에 통과했습니다. 실제 초등학생 체험 시간은 아닙니다.

## 한계

자동 검증은 그래픽 API를 대체한 실행 환경에서 수행했습니다. 실제 브라우저 화면·GPU·태블릿 터치는 확인하지 못했습니다. 첨부 이미지의 의도에 맞게 꺾이는 모서리만 선택했으며, 최종 시각적 위치와 길이는 실제 화면에서 추가 확인이 필요합니다. 새 맵 장식의 가독성 역시 실제 화면에서 확인해야 합니다.

## 자막·배경 수정 확인

자막을 상단으로 이동하고 단계 표시 영역과 분리한 좌표를 확인했다. 배경 직육면체 일곱 개를 생성하던 코드 제거와 JavaScript 구문을 확인했다. 실제 브라우저 화면은 미검증이다.

## 도착 접촉 전환

세 맵 모두 목표 밖에서는 전환하지 않고, 속도 8로 목표 가장자리에 닿는 첫 계산 프레임에 다음 단계로 전환함을 확인했다. 마지막 전시실은 즉시 결과 화면으로 이동한다.

## 실패 UI 제거와 확대

세 맵 모두 실패 상태에서 팝업·실패 자막이 그려지지 않고, 복귀 후에도 복귀 자막 없이 저장 지점으로 돌아옴을 자동 확인했다. 카메라의 고정 투영 범위를 20% 확대에 해당하는 값으로 변경했다. 실제 확대 구도는 브라우저에서 추가 확인이 필요하다.

## 하단 버튼과 바로 시작 확인

네 방향 버튼의 새 위치에서 터치 판정이 일치함을 확인했다. 2·3단계는 소개 없이 바로 플레이하며 도착 접촉 전환도 유지된다. 시작 화면에서 두 문구가 제거됨을 확인했다. 실제 화면·터치는 미검증이다.
