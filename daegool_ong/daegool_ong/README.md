# 데굴데굴 옹기 — 조이스틱 버전

index.html을 최신 Edge 또는 Chrome에서 여세요. 인터넷이나 설치 없이 실행하는 단일 HTML입니다. 태블릿은 가로로 사용합니다.

## 옹기 선택과 설명

선택지가 6종으로 늘었습니다. 동글옹기, 길쭉옹기, 납작옹기, 꼬마옹기, 목긴옹기, 반듯옹기 중 하나를 누르면 오른쪽 설명 패널이 바뀝니다. 큰 3D 미리보기, 형태 특징, 관찰 질문을 보여주며 선택한 친구로 이야기·플레이·결과까지 이어집니다.

이름은 게임용 별명이고 설명은 게임 모델의 형태를 관찰하는 내용입니다. 실제 소장품명·용도·시대·사진·출처·사용 허가는 확인 후 반영합니다. 확인하지 않은 소장품 사실을 지어 넣지 않습니다.

## 조작

- 가운데 아래 조이스틱을 원하는 방향으로 밀어 움직입니다.
- 조금 밀면 천천히, 많이 밀면 더 빠르게 기울어집니다.
- 손을 놓으면 판이 부드럽게 수평으로 돌아옵니다. 옹기는 관성으로 조금 더 굴러가므로 위험 앞에서 미리 놓으세요. 추가 감속은 적용하지 않습니다.
- 최대 기울기는 기존과 같은 25도이며 작은 손 떨림은 무시합니다.
- 조이스틱 밖으로 끌어도 방향 입력을 유지하며, 손을 떼거나 터치가 취소되면 해제됩니다.
- 키보드 화살표도 보조 입력으로 지원합니다. 네 방향 터치 버튼은 제거했습니다.

## 진행

공방 → 가마 앞 → 전시실 세 단계입니다. 첫 단계만 소개하며, 이후는 바로 시작합니다. 초록 안전 지점은 닿으면 저장되고 도착 지점도 닿는 즉시 넘어갑니다.

구멍, 왕복 도구, 무너지는 발판은 위험합니다. 모서리에만 짧은 충돌 벽이 있고, 다른 가장자리에서는 떨어질 수 있습니다. 실패 시 팝업 없이 저장 지점으로 조용히 돌아옵니다.

기존 맵 크기, 단순한 전체 화면 배경, 눈 없는 옹기, 시작 화면 정리와 UI 삭제 사항은 유지합니다.

## 확인 상태

작은 입력 무시, 방향·세기, 한 손가락 입력 소유, 손 떼기·취소·입력 캡처 해제, 수평 복귀와 관성 유지, 세 단계 통과를 자동 검증했습니다. 실제 브라우저 화면과 태블릿 손맛은 아직 확인하지 못했습니다.

기본 WebGL을 사용하며 모든 UI는 하나의 WebGL canvas 안에 표시합니다. npm·Vite·CDN·외부 폰트 없이 동작합니다. Three.js는 포함하지 않습니다. 실제 소장품 사진·명칭·설명·사용 허가는 확인 전이며 자리표시자를 유지합니다.

조이스틱은 하단 중앙, 기울기 표시는 하단 오른쪽에 배치합니다. 손을 놓으면 판이 부드럽게 수평으로 돌아오며, 기존 관성과 기본 마찰은 유지합니다.

## 수평 복귀 속도 완화

수평 복귀 시간을 직전 버전의 약 두 배로 늘린다. 약 1초에 95% 복귀하며, 조이스틱 입력과 마찰·관성은 유지한다.
