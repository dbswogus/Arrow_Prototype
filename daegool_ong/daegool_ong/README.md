# 데굴데굴 옹기 — 세 가지 맵과 옹기

index.html을 최신 Edge 또는 Chrome에서 여세요. 인터넷이나 별도 설치가 필요 없는 단일 HTML입니다. 태블릿은 가로로 사용합니다.

## 이번 변경

- 시작 화면은 옹기 한 개와 바닥 그림자로 정리하고, 겹치던 받침대와 작은 옹기를 제거했습니다.
- 공방의 옹기 세 개가 놓인 작업대 장식을 제거했습니다.
- 배경과 canvas를 화면 전체에 채웁니다. 게임·UI 비율은 유지하고, 남는 공간도 같은 배경색으로 채웁니다.
- 플레이 화면의 왼쪽 제목·단계 설명, 중앙 목표 상자, 속도 창, 아래 저장·제동 안내 문구를 제거했습니다. 단계 표시·재도전 상태·조작 버튼·기울기 표시는 유지합니다.


- 공방은 넓은 작업 마당과 작업대를 돌아 위아래로 꺾이는 지그재그 길입니다.
- 가마 앞은 두 커다란 가마 사이를 세 개의 긴 나무 다리가 번갈아 잇습니다. 출발과 도착 방향도 공방과 다릅니다.
- 전시실은 큰 바깥 통로를 돌아 안쪽으로 들어가는 구조이며 최종 목적지는 중앙 전시대입니다.
- 옹기의 눈과 깜빡임을 제거하고 기본 외형을 사용합니다.
- 캐릭터 간 물리 규칙을 설명하던 문구는 선택 화면에서 삭제했습니다.
- 모서리에만 짧은 벽, 벽 없는 구간의 낙하, 접촉 즉시 저장, 세 단계와 전시실 결말은 유지합니다.

## 조작과 위험

화면의 네 방향 버튼 또는 키보드 화살표로 판을 기울입니다. 누르는 동안 기울기가 커지고, 놓으면 유지됩니다. 반대로 기울여 제동하세요. 점프는 없습니다.

모서리의 짧은 벽은 실제로 옹기를 막습니다. 벽 없는 가장자리, 구멍, 왕복 도구 접촉, 무너진 발판은 실패로 이어집니다. 마지막 안전 지점에서 속도와 기울기를 초기화해 다시 시작합니다.

| 단계 | 기믹 |
|---|---|
| 공방 | 넓은 작업 마당, 되돌아 꺾이는 지그재그 길, 구멍 세 곳 |
| 가마 앞 | 세 개의 긴 나무 다리, 두 큰 가마, 구멍 한 곳, 왕복 장애물 두 개 |
| 전시실 | 외곽 순환 통로, 중앙 전시대, 전시 진열장, 구멍 두 곳·왕복 도구·금 간 판 |

금 간 발판은 최초 접촉 2.2초 뒤 무너지고 2.8초 후 복구됩니다. 안전 지점은 닿으면 저장됩니다. 각 단계의 마지막 초록 목표도 닿는 즉시 다음 단계로 넘어가며, 마지막 전시실은 바로 결과 화면으로 이동합니다.

## 확인 상태

벽이 있는 부분과 실제 충돌 부분이 일치하는지, 열린 가장자리에서 낙하하는지, 접촉 저장과 세 단계 통과가 가능한지 자동 검증했습니다. 실제 브라우저 화면·GPU·태블릿 터치는 미검증입니다.

기본 WebGL을 사용하며 Three.js는 포함하지 않습니다. 모든 UI는 단일 WebGL canvas 안에 표시됩니다. npm·Vite·CDN·원격 글꼴은 사용하지 않습니다. 실제 소장품 사진·명칭·설명·출처·사용 허가는 확인 전이며 자리표시자를 유지합니다.

## 자막과 배경 정리

플레이 중 임시 안내 자막은 상단 왼쪽(기준 좌표 x=64, y=42)에 배치하고 오른쪽 단계 표시와 겹치지 않게 한다. 배경 위쪽에 줄지어 있던 직육면체 일곱 개는 모든 맵에서 제거한다.

## 조용한 복귀와 맵 확대

실패 시 팝업과 실패·복귀 자막을 표시하지 않고, 낙하 연출 후 저장 지점에 조용히 복귀한다. 기존 단계 표시와 재도전 횟수는 유지한다. 배경에 장식을 추가하지 않고 플레이 맵을 20% 확대하며 고정 카메라를 유지한다.

## 하단 조작과 단계 전환 개정

맵을 직전 버전보다 10% 축소한다. 방향 버튼은 하단에 왼쪽부터 ← ↑ / ↓ → 순서로 나눠 배치하고 기존 십자형 패널을 없앤다. 시작 화면의 기술 요약 배지와 경사·관성 홍보 문구를 삭제한다. 1단계 소개는 유지하고 2·3단계는 소개 화면·시작 자막 없이 바로 플레이한다.
